# 🧧 Xoay Lì Xì May Mắn

Ứng dụng web giúp bạn tạo trò chơi xoay lì xì may mắn với giao diện đẹp mắt và hiệu ứng sinh động!

## 🎯 Tính năng

- ✨ **Thêm Lì Xì**: Thêm phong bì lì xì với số tiền tùy ý
- 🎰 **Xoay May Mắn**: Xoay vòng để chọn ngẫu nhiên phong bì trúng thưởng
- 🎨 **Giao diện đẹp**: Thiết kế hiện đại với màu đỏ vàng truyền thống
- 🎉 **Hiệu ứng**: Animation mượt mà, confetti khi trúng thưởng
- 📊 **Thống kê**: Hiển thị tổng số phong bì và tổng tiền

## 🚀 Cách sử dụng

### Mở ứng dụng
1. Mở file `index.html` bằng trình duyệt web (Chrome, Firefox, Edge...)
2. Hoặc kéo thả file `index.html` vào cửa sổ trình duyệt

### Thêm lì xì
1. Click nút **"Thêm Lì Xì"** (màu vàng)
2. Nhập số tiền vào ô input (ví dụ: 50000, 100000, 200000...)
3. Click **"Thêm Ngay"** hoặc nhấn Enter
4. Phong bì sẽ xuất hiện và xếp thành vòng tròn

### Quay lì xì
1. Thêm ít nhất **2 phong bì** trở lên
2. Click nút **"Quay Ngay!"** (màu đỏ)
3. Chờ vòng quay dừng lại (khoảng 3 giây)
4. Xem kết quả người trúng thưởng với hiệu ứng confetti 🎉
5. Click **"Quay Lại"** để quay tiếp

- **Hiệu ứng**:

  - Animation xoay mượt mà
